# FastAPI Service

Spazio riservato al futuro servizio FastAPI per HAR/AI inference.

Idea di responsabilita:

- ricevere finestre sensoriali o batch di viaggio dal backend Ninja;
- normalizzare/adattare input se necessario;
- eseguire modelli HAR pesanti;
- restituire predizioni o correzioni finali al diario.

Per ora e uno scheletro separato, cosi il backend Django Ninja resta pulito.

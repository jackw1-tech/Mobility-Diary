# Auto-Confirmed Places Enter The Diary With Neutral Text

Status: accepted

When a Luogo Candidato reaches automatic confirmation through recurring evidence across distinct days, it should already enrich matching stop descriptions in the Diario della Mobilita even before the user manually reviews or labels it. We considered requiring explicit user confirmation before any diary usage, but allowing neutral diary wording gives immediate product value while still reserving semantic names and categories for later manual refinement.

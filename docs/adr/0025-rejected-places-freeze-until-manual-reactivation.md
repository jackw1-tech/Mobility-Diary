# Rejected Places Freeze Until Manual Reactivation

Status: accepted

When a user rejects a Luogo Candidato, the first implementation should freeze that place permanently from automatic reconsideration until the user explicitly reactivates it. We considered a temporary quarantine that would allow the same area to reappear after enough new evidence, but the permanent freeze keeps the product behavior simpler and prevents the system from repeatedly proposing a place the user has already dismissed.
